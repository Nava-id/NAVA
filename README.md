# NAVA Builder V1
Satu builder lokal untuk membuat website klien.

Fitur:
- Kelas Rp299K / Rp499K / Rp650K / Custom
- Template Restoran, Cafe, Toko, Jasa
- Drag-and-drop urutan section
- Tambah/hapus section
- Edit teks, tombol, menu/produk
- Warna custom
- WhatsApp
- Preview
- Simpan/muat project di browser
- Export website HTML

Buka `index.html` di browser.

V1 adalah frontend/local builder. Untuk versi online multi-user diperlukan backend, database, login, storage gambar, publishing, dan domain/subdomain automation.
